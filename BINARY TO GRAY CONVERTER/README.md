# 4-Bit Binary to Gray Code Converter in Verilog

## Description

This project implements a **4-bit Binary to Gray Code Converter** using Verilog HDL.

The circuit converts a 4-bit binary input into its equivalent 4-bit Gray code output.

Gray code is a binary numeral system in which two consecutive values differ by only one bit.

## Features

- 4-bit Binary-to-Gray converter
- Combinational logic circuit
- No clock required
- No reset required
- Tests all 16 possible input combinations
- Compatible with Visual Studio Code
- Simulated using Icarus Verilog

Applications

Binary-to-Gray converters are commonly used in:

Rotary encoders
Digital communication
Position sensors
Error reduction
Analog-to-digital converters
FPGA and digital logic design
